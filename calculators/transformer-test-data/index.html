Transformer OC and SC Test Formula

cos φ₀ = P₀ / (√3 V₀ I₀) Rc = a² V₀φ² / P₀φ Y₀ = I₀ / V₀φ, G = P₀φ / V₀φ², B = √(Y₀² − G²), Xm = a² / B R = Pscφ / Isc², Z = Vscφ / Isc, X = √(Z² − R²) Pcu = Psc (Irated / Isc)² E = |Vφ + x Irated (cos φ ∓ j sin φ)(R + jX)|, regulation = (E − Vφ) / Vφ η = x S pf / (x S pf + P₀ + x² Pcu) x_max = √(P₀ / Pcu) a = V1 / V2

Assumptions and Limitations

  • Values are for the equivalent star: each phase carries the line voltage divided by √3 and one third of the total power. A single-phase transformer uses the readings as they are
  • The open-circuit test is taken on the LV side at rated voltage and the short-circuit test on the HV side at about rated current. The magnetising branch is referred to the HV side by the square of the voltage ratio a = V1 / V2, so both branches are on the same side
  • The core loss is taken as the open-circuit power as measured; it is not corrected if the test voltage is not rated, and a warning is shown if it is more than 5% away. The copper loss is scaled from the test current to rated current by the square of the current ratio
  • The series branch uses the short-circuit result alone, with the magnetising branch left out; this is the usual approximate equivalent circuit. The short-circuit resistance is the winding resistance at the test temperature, not corrected to a reference winding temperature
  • Regulation uses the exact phasor sum of the series drop, not the approximation; efficiency counts only the core and copper losses, so stray, dielectric and cooling losses are not included
  • Efficiency is highest at the load where the copper loss equals the core loss; the maximum efficiency is given at the same power factor as the chosen load
