About this calculator

This page calculates percentage error, absolute percentage error, error and 2 more results from measured value and true value. Change any value or its unit and the result updates. The steps below show the working for the default values, so you can check each line against your own method.

Limits of this calculator

Use the absolute percentage error when only the size of the error matters, such as checking a meter against a tolerance. Percentage error is not the same as percentage difference, which compares two values with neither one a reference. For the uncertainty of a measurement chain see the measurement uncertainty guide.

Formula

Error = measured − true Absolute error = |measured − true| Relative error = (measured − true) / |true| Percentage error = relative error × 100

Worked example

InputValue
Measured value98.5
True (reference) value100
  1. Error = measured − true = 98.5 − 100 = -1.5
  2. Absolute error = |-1.5| = 1.5
  3. Relative error = error / |true| = -1.5 / 100 = -0.015
  4. Percentage error = -0.015 × 100 = -1.5%

Assumptions

  • Percentage error is taken relative to the true (reference) value, not the measured one
  • A negative percentage error means the measured value is below the true value; a positive one means it is above
  • Both values are plain numbers in one consistent unit; the percentage does not depend on the unit
  • The true value must not be zero

How it is calculated

Each input is converted to the base unit of its quantity, the formula above is applied in the order shown in the worked example, and each result is shown in the unit you choose. Results are held at full precision and rounded only for display, except where a step selects a standard size, as the worked example shows. A value outside its allowed range is refused with a message instead of giving a result.

Frequently asked questions

What do I need to enter?

Enter measured value and true (reference) value. Change the unit of a value with its selector and the result stays the same.

What does this calculator assume?

Percentage error is taken relative to the true (reference) value, not the measured one. A negative percentage error means the measured value is below the true value; a positive one means it is above. Both values are plain numbers in one consistent unit; the percentage does not depend on the unit. The true value must not be zero.
