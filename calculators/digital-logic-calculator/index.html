    Questions

    What can I type as a Boolean expression?

    Use the letters A to Z as variables and the operators AND, OR, NOT, XOR, NAND, NOR and XNOR, or the symbols & | ! ^ and +, or a prime after a variable as in A'. Letters written together mean AND, so AB is A AND B. Brackets work as usual. Precedence is NOT first, then AND and NAND, then XOR and XNOR, then OR and NOR. Up to 6 variables.

    How does the calculator find the minimal expression?

    It lists every prime implicant with the Quine-McCluskey method and then searches for the cover with the fewest product terms, and the fewest literals among those. The search is exact, so the result is minimal, and both the minimal SOP and POS are checked against every row of the truth table before they are shown.

    What are minterms and maxterms?

    A minterm is a row of the truth table where the output is 1, numbered by reading the inputs as a binary number with the first variable as the most significant bit. A maxterm is a row where the output is 0. The sum of minterms Σm(...) and the product of maxterms ΠM(...) describe the same function.

    What is a don’t-care?

    An input combination that never happens, or whose output does not matter. Write it as d(...) after the minterm list, for example m(1,3,5,7) d(0). The simplifier may treat it as 0 or 1, whichever gives a smaller expression.

    How do I check that two expressions are equivalent?

    Type the second one in “Compare with”. The calculator compares the two over every input combination of all the variables used and lists the rows where they differ, so De Morgan’s laws, absorption and your own simplifications can be checked.

    What does the gate diagram show?

    The expression drawn as gates, with the input values you choose (A=1, B=0, or the bits in order). Highlighted wires carry 1 and grey wires carry 0, so you can follow the signal to the output. If you leave the inputs empty it uses the first row where the output is 1.

    How do bit masks and bit fields work?

    OR with a mask sets the masked bits to 1. AND with the inverted mask clears them. XOR flips them. AND with the mask keeps only the masked bits. A mask can be written as bit positions (0,3,5-7), a range (7:4), or a pattern (0xF0, 0b11110000). What are bit fields? Named groups of bits in a register, such as MODE in bits 7 and 6. Write them as NAME:high:low (MODE:7:6) or NAME:bit (EN:5). The calculator shows each field’s value in binary, hex and decimal.

    What is a parity bit?

    An extra bit added so that the total number of 1s is even (even parity) or odd (odd parity). It detects any single flipped bit and any odd number of flipped bits, but misses an even number of flips and cannot say which bit is wrong or correct it.

    What is the difference between big-endian and little-endian?

    It is the order in which the bytes of a multi-byte value are stored. Big-endian puts the most significant byte first, as written on paper and used on networks. Little-endian puts the least significant byte first, as in x86 and most ARM systems.

    Is anything sent to a server?

    No. Everything runs in your browser, and the history list is stored only in your browser.
