About this calculator

This page calculates slope m, grade, angle from the horizontal and 5 more results from point 1, x, point 1, y, point 2, x and point 2, y. Change any value or its unit and the result updates. The steps below show the working for the default values, so you can check each line against your own method.

Limits of this calculator

Use this to check the fall on a cable trench or drain, the gradient of a conduit or cable-tray run, the pitch of a ramp or access road, or the slope between two surveyed levels. For the straight-line distance between the points use the distance calculator, and for a value between two known points use the linear interpolation calculator.

Formula

m = (y₂ − y₁) / (x₂ − x₁) grade = 100 m angle = atan(m) 1 in N: N = run / rise length = √(run² + rise²) y = m x + b, b = y₁ − m x₁

Worked example

InputValue
Point 1, x0
Point 1, y0
Point 2, x20
Point 2, y1
  1. Rise = y₂ − y₁ = 1 − 0 = 1 Run = x₂ − x₁ = 20 − 0 = 20
  2. Slope m = rise / run = 0.05 Grade = 100 m = 5%
  3. Angle = atan(m) = 2.86240523° Run per unit rise = 20 (1 in 20)
  4. Length = √(run² + rise²) = 20.0249843945 y-intercept b = y₁ − m x₁ = 0

Assumptions

  • The two points are joined by a straight line and the slope is the same everywhere along it
  • Slope is rise divided by run. A positive slope rises from point 1 to point 2, a negative slope falls, and the order of the points does not change the slope
  • Grade is the slope as a percentage, so a grade of 5% rises 5 units for every 100 units of run. "1 in N" is the same gradient written as the run needed for one unit of rise
  • A vertical line (the two x values equal) has no defined slope, grade, 1-in-N or y-intercept; its angle is 90° and its length is still found. A level line has slope zero and no 1-in-N figure
  • The tool works on plain numbers and does not track units: enter all four values in the same unit; the slope, grade and angle do not depend on which unit that is
  • Identical points do not define a line and are rejected

How it is calculated

Each input is converted to the base unit of its quantity, the formula above is applied in the order shown in the worked example, and each result is shown in the unit you choose. Results are held at full precision and rounded only for display, except where a step selects a standard size, as the worked example shows. A value outside its allowed range is refused with a message instead of giving a result.

Frequently asked questions

What do I need to enter?

Enter point 1, x, point 1, y, point 2, x, point 2 and y. Change the unit of a value with its selector and the result stays the same.

What does this calculator assume?

The two points are joined by a straight line and the slope is the same everywhere along it. Slope is rise divided by run. A positive slope rises from point 1 to point 2, a negative slope falls, and the order of the points does not change the slope. Grade is the slope as a percentage, so a grade of 5% rises 5 units for every 100 units of run. "1 in N" is the same gradient written as the run needed for one unit of rise. A vertical line (the two x values equal) has no defined slope, grade, 1-in-N or y-intercept; its angle is 90° and its length is still found. A level line has slope zero and no 1-in-N figure. The tool works on plain numbers and does not track units: enter all four values in the same unit; the slope, grade and angle do not depend on which unit that is. Identical points do not define a line and are rejected.
