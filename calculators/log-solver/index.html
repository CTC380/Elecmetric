Three unknowns, one equation

The logarithm log_b(x) = y and the exponential b^y = x say the same thing. If you know any two of b, x and y, the third follows:

You knowLeave blankFormulaExample
b and xyy = log_b(x) = ln x ÷ ln blog₂(64) = 6
b and yxx = b^y10^3 = 1000
x and ybb = x^(1/y)125^(1/3) = 5

Finding y uses change of base, y = ln x ÷ ln b, and is the same calculation as the Log Calculator in Mode 01. Finding x is the antilogarithm of Mode 02. Finding b takes the y-th root of x: raise both sides of b^y = x to the power 1/y. The three modes share one engine, so they can never give different answers.

Finding the base

Write y as a fraction p/q in lowest terms. Then b = x^(q/p): take the p-th root of x and raise it to the power q. Solve log_b(125) = 3 and you get b = 125^(1/3) = 5 because 5³ = 125. Solve log_b(8) = −3 and you get b = 8^(−1/3) = 1/2 because (1/2)^(−3) = 8, a base between 0 and 1.

The base is exact when the numerator and the denominator of x are both perfect p-th powers (for a negative y, of 1/x). Otherwise it is irrational, and the page gives a decimal and, for a fractional y, the simplest radical form:

A logarithm base must be positive, so the real root is unique. For x = 9 and y = 2, b² = 9 has two roots, 3 and −3, but only b = 3 can be a base.

When there is no answer, or every base works

The solver sorts every result into one of three kinds. Most questions have exactly one valid answer. Two cases do not:

x = 1, y = 0Not a single answerb^0 = 1 for every base b, so log_b(1) = 0 whatever the base is (b > 0, b not 1).
x = 5, y = 0No valid baseNo base gives log_b(5) = 0, because b^0 = 1, never 5.
x = 1, y = 5No valid baseThe only positive number with b^5 = 1 is b = 1, which cannot be a logarithm base.
x = 9, y = 2One valid baseb = 3

If x = 1 and y = 0, every valid base works because b⁰ = 1 for any b. If x = 1 and y is not 0, the only number with b^y = 1 is b = 1, which cannot be a logarithm base. If y = 0 and x is not 1, no base gives x as b⁰. The page says which of these applies instead of showing a wrong number.

Checking all three values

Fill in all three fields and the solver tells you whether log_b(x) = y is true. It compares y with the actual logarithm. When the logarithm is rational the comparison is exact: log₂(8) = 3 holds and log₂(8) = 4 does not, and the page shows the true value. When the logarithm is irrational it can never equal a fraction or a decimal you type, so a rounded value such as log₂(3) = 1.5849625 is reported as not exact. Leave a field blank to get the precise value.

Questions

Which value can I leave blank?

Any one of the three. Leave y blank to find the logarithm, x blank to find the argument, b blank to find the base. Leaving two blank is not enough information, and filling all three runs a consistency check instead.

Why does the base have only one answer when y is even?

For an even whole number y, both b and −b satisfy b^y = x. A logarithm base must be positive, so the negative root is excluded and the answer is unique.

When is the base exact?

When the numerator and the denominator of x (swapped for a negative y) are both perfect p-th powers, where p is the numerator of y in lowest terms. log_b(125) = 3 gives 5 and log_b(2) = 1/2 gives 4 exactly. log_b(2) = 3 gives the cube root of 2, which is irrational, so only a decimal and the radical form can be shown.

Why does log_b(1) = 5 have no answer?

b^5 = 1 only for b = 1 among positive numbers, and 1 is not allowed as a logarithm base. With y = 0 the opposite happens: log_b(1) = 0 is true for every base, so there is no single answer.

How large can the base or argument be?

Up to 10 raised to ±1,000,000,000, kept as a mantissa and an exponent. A larger size is refused with a message because it could not be shown.

How is an answer checked?

An exact answer is checked by exact arithmetic against the Mode 01 engine. Every answer is also checked in 90-digit arithmetic and against a double-precision calculation. The engine is tested against independent reference values from a computer algebra system.

Is anything sent to a server?

No. The calculation runs in your browser. The history list is stored only in this browser and you can clear it.
