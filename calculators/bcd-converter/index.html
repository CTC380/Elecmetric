    BCD encodes each decimal digit separately. It uses more bits than plain binary, but it maps directly to seven-segment displays and decimal arithmetic.

    Questions

    What is BCD?

    Binary Coded Decimal writes each decimal digit as its own 4-bit group. 25 is 0010 0101, not 11001. Groups 1010 to 1111 never appear in valid BCD.

    What is the difference between packed and unpacked BCD?

    Packed BCD stores two digits per byte. Unpacked BCD stores one digit per byte with the upper four bits zero.

    What is Excess-3?

    Excess-3 adds 3 to each digit before encoding, so 0 is 0011 and 9 is 1100. It is self-complementing: inverting every bit gives the 9’s complement, which simplifies subtraction circuits.

    Why is 1010 rejected?

    1010 is 10, which is not a decimal digit. In Excess-3 the valid groups are 0011 to 1100.

    Are negative numbers and decimals supported?

    Not yet: the page encodes whole non-negative numbers, up to 200 digits. Signed BCD formats differ between systems.

    Is anything sent to a server?

    The calculator runs in your browser. This page also loads Google Tag Manager; data collected by tags depends on its configuration.
