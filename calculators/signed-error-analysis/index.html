The signed error is −5 V, which is ≈ −2.174% of 230 V to three decimal places. The negative sign means the observed value is below the reference.

The signed error formulas

Signed error e = Observed − Reference

Signed deviation = e ÷ |Reference| × 100

The first line is the definition of measurement error in the International Vocabulary of Metrology (VIM): the measured quantity value minus a reference quantity value. The second divides by the size of the reference, so the sign of the answer comes only from the error. The absolute error and the percent error of Mode 01 are the sizes of these two results.

Positive: the observed value is above the reference. Zero: they are equal. Negative: the observed value is below the reference. A positive sign does not mean the reading is better or worse. It only gives the direction.

Worked example: 225 V against a reference of 230 V

StepWorking
Step 1Find the error: observed − reference = 225 − 230 = −5, keeping the sign. The signed error is −5 V.
Step 2The sign gives the direction: negative, so the observed value is below the reference.
Step 3Divide the error by the reference: (−5) ÷ 230 = −1/46. This is the signed relative error.
Step 4Multiply by 100: (−1/46) × 100 = −50/23%. The signed percentage deviation is ≈ −2.173913%.
Step 5Check: reference + (−50/23)% of 230 = 225, the observed value you entered.
Step 6The observed value is 5 V below the reference, a deviation of ≈ −2.173913%. To bring it back to the reference, apply a correction of +5 V.

Negative reference values

The page divides by the size of the reference. That keeps the rule simple: a reading that is numerically higher than the reference always has a positive deviation. For −9 V against −10 V the reading is 1 V higher, so the deviation is +10%. Dividing by the reference with its sign would flip the sign of the percentage. Some data sets use that convention, so check which one your source uses.

Calibration certificates usually report the error of indication as indication minus reference, the same as this page. A correction is the opposite: it is what you add to the reading to reach the reference, so it has the opposite sign. Some textbooks define the error as true value minus measured value. When you compare results, check the direction first.

Signed error is not uncertainty, tolerance or accuracy

The signed error is the difference between an observed and a reference value. Measurement uncertainty describes the dispersion of values that could reasonably be attributed to the measurand, and is reported separately. Tolerance is a limit set by a specification. Accuracy, repeatability and conformity need defined criteria. A signed deviation of −2% does not mean 98% accuracy, and this page does not say whether an error is acceptable under your standard or manufacturer data.

Questions

What is signed error?

It is the observed value minus the reference value, with the sign kept. For 225 V against 230 V it is −5 V: the reading is 5 V below the reference.

How is the signed percent deviation calculated?

Divide the signed error by the size of the reference and multiply by 100. For 225 V against 230 V, −5 ÷ 230 × 100 = ≈ −2.173913%.

What does a negative sign mean?

The observed value is below the reference. A positive sign means it is above. Zero means they are equal.

What is the difference between signed error and absolute error?

The absolute error is the size of the signed error, with no sign. Use the signed error when the direction matters, for example to see whether an instrument reads high or low.

What is the correction?

The correction is what you add to the observed value to reach the reference. It has the opposite sign to the signed error: +5 V for a reading 5 V low.

What if the reference is 0?

The page refuses it, because a percentage of 0 is not defined. The signed error itself is still observed minus reference.

What if the reference is negative?

The page divides by the size of the reference, so a reading that is numerically higher than the reference is always positive. For −9 V against −10 V the deviation is +10%.

Does the unit change the answer?

No. The unit is a label shown beside the errors and the correction. The page does not convert between units, so enter both values in the same unit.
