How the numbers are made

With no seed, every number is built from bits supplied by your browser’s Web Crypto generator. To pick a whole number from an inclusive range, the tool draws just enough bits to cover the range and throws the draw away if it lands outside it. This is called rejection sampling. It avoids the small bias you get from taking a remainder (the modulo trick), so every value in the range has exactly the same chance.

With duplicates switched off, numbers are drawn without replacement using a partial Fisher-Yates shuffle, so a quantity equal to the size of the range gives every value once, in random order.

Integers are handled as arbitrary-precision numbers, so the minimum and maximum can each be up to 1,000 digits long and the results are exact.

How decimals are chosen

Decimals are drawn from a fixed grid: with 2 decimal places, 1 to 100 means the 9,901 numbers 1.00, 1.01, 1.02 up to 100.00. Each grid value is mapped to a whole-number position, one position is chosen with equal probability, and the result is written with exactly that many decimal places. The tool never generates a floating-point number and rounds it afterwards, so each grid value has precisely the same chance and nothing is lost to binary rounding. If your minimum or maximum falls between grid points (for example 0.15 with 1 decimal place), it is moved inward to the nearest grid point.

Unique numbers mode

Unique numbers mode always draws without replacement, for whole numbers or decimals. You can list numbers to leave out: they are removed from the pool first, then the draw is made among the numbers that remain, so every remaining number is equally likely and an excluded number can never appear. Asking for as many numbers as the pool holds gives a complete random shuffle. The page also shows the pool size, the chance that any one number is picked, and how many different sets and orderings are possible (for 6 numbers from 1 to 49 that is 13,983,816 sets).

Statistical sampling mode

Statistical sampling draws numbers from a probability distribution instead of a flat range: normal (mean and standard deviation), uniform, exponential (rate), triangular (minimum, mode, maximum), Poisson (mean) and binomial (trials and success probability). Every distribution starts from uniform numbers made from 53 random bits, strictly between 0 and 1. A normal sample uses the Box-Muller transform, exponential and triangular samples use the inverse of the cumulative distribution, and Poisson and binomial samples use inversion by sequential search. Continuous values are rounded to the decimal places you choose, and the statistics and histogram describe the rounded values listed, next to the theoretical mean and standard deviation of the distribution so you can see how close a sample of that size gets.

These are simulated, synthetic numbers. They are not measured data and they are not a validated physical model, so do not use them in place of real measurements or a proper engineering analysis.

Engineering test data mode

Engineering test data mode builds a small dataset: up to 8 parameters (columns) and up to 10,000 observations (rows). For each parameter you give a name, a unit, a minimum and a maximum, the number of decimal places and a distribution, and optionally a typical value and a measurement tolerance. Uniform gives every value in the range the same chance. Normal is a bell curve centred on the typical value (the middle of the range if you leave it empty) with a standard deviation of one sixth of the range, so the limits sit three standard deviations away when it is centred; any draw outside the limits is thrown away and drawn again, so the values never leave the range. Triangular peaks at the typical value. Log-uniform gives every factor of ten the same chance, which suits resistance and insulation readings that span several decades and needs a minimum above 0.

If you enter a tolerance (an amount in the unit, such as 0.5, or a percentage of each value, such as 1%), a second column is added next to the values. Each measured value is the simulated value plus an error that is equally likely anywhere between minus and plus the tolerance, rounded to the same decimal places. It models an instrument that stays within its stated band, so measured values can fall slightly outside the minimum and maximum. In a seeded run every column has its own stream (your seed text plus the column number), so editing one parameter, or switching a tolerance on, leaves the other columns unchanged. Results show the table, summary statistics for each parameter and a histogram per parameter, and the data can be copied for a spreadsheet or downloaded as TXT, CSV or JSON.

Synthetic data. Everything in this mode is simulated. It is test data for checking calculations, software and spreadsheets, not field measurements, equipment test results or compliance evidence. Every row of every export carries the label SYNTHETIC, and the JSON file repeats this in a note.

Seeded mode

If you enter a seed, the numbers come from a documented pseudorandom generator instead (the seed text is hashed with cyrb128 and the result drives sfc32). The same seed and settings always return the same numbers, which is useful for repeating a test of a calculation or a simulation. A seed makes the output predictable, so it is not secure.

These are pseudorandom numbers for general use: sampling, games, classroom exercises and testing. Do not use this page to make passwords, keys, tokens or anything else where an attacker guessing the number would matter.

Questions

How do I generate random numbers in a range, including negative or very large ones?

Leave the minimum at 1 and the maximum at 100, choose how many numbers you want, and press Generate. Both ends are included, so 1 and 100 can each come up. Can I use negative numbers or very large numbers? Yes. The minimum can be negative, and the minimum and maximum can each be up to 1,000 digits long. Results are exact whole numbers.

How do I get numbers that never repeat, and can I leave some out?

Set Duplicates to “No duplicates (unique)”. The quantity cannot be larger than the number of values in the range (for decimals, the number of grid values): six unique numbers from 1 to 49 works, but ten unique numbers from 1 to 5 does not. What does Unique numbers mode do? It draws numbers that never repeat, like drawing balls from a drum. Set the minimum, maximum and how many you need, add numbers to exclude if some are not allowed, and press Generate. It suits lottery-style picks, raffles, random samples of IDs or rows, and shuffling a list of numbers. Can I leave some numbers out? Yes. In Unique numbers mode, type the numbers to exclude in the box (separated by commas, spaces or new lines). Numbers outside the range, or not on the decimal grid, are ignored and listed under the results. If the quantity is larger than what is left, you get a clear message.

Are the numbers truly random, and what is the seed for?

They are pseudorandom. Without a seed they come from the browser’s Web Crypto generator, which is a high-quality source, and each value in the range is equally likely. Do not rely on this page for passwords, keys or security tokens. What is the seed for? A seed makes the result repeatable. Entering the same seed with the same range, quantity and options gives the same list every time, so you can reproduce a test run. It is meant for testing and simulation and is not secure.

How do I generate random decimals?

Set Number type to Decimals, choose 0 to 15 decimal places, and enter the minimum and maximum. For 2 decimal places between 1 and 100, every number from 1.00 to 100.00 in steps of 0.01 is equally likely. Are decimals picked from a continuous range? No. They are picked from the grid of numbers with the chosen number of decimal places, which is what a value written to that precision is. This keeps every value equally likely and the digits exact.

What is the difference between sets and orderings?

A set ignores the order: 6 numbers from 1 to 49 can form 13,983,816 different sets. An ordering counts the same numbers in a different order as different results: 10,068,347,520 ordered ways. Every set is equally likely.

How do I generate several sets at once, and are they independent?

Enter a Number of sets from 1 to 50. Each set uses the same settings and is generated independently, so five sets of six unique numbers gives five separate lottery-style draws. The page lists every set, shows mean, median and standard deviation for each, and lets you pick one set to see its working and charts. Copy and download include all the sets, with a set number on every row of CSV. Are the sets really independent, and can I repeat them? Without a seed, every set draws its own fresh bits from Web Crypto. With a seed, set 1 uses the seed exactly as typed and set 2 onwards use the seed followed by a set marker, so each set is an independent stream and the whole run is repeatable. Adding more sets never changes the earlier ones.

Which distributions can I sample, and why is my sample mean not exactly the theoretical mean?

Normal, uniform, exponential, triangular, Poisson and binomial. Choose one under Statistical sampling, enter its parameters and the quantity, and press Generate. You get the list, the statistics, a histogram and the working. Why is my sample mean not exactly the theoretical mean? A sample is random, so its mean and standard deviation scatter around the theoretical values, and the scatter shrinks as the quantity grows (roughly in proportion to one over the square root of the quantity). A sample of 10,000 normal numbers typically has a mean within about 1% of one standard deviation of the true mean.

Can I use this for Monte Carlo or test data?

Yes for simple cases: a seeded sample is repeatable, so a test or simulation can be rerun with the same numbers. The numbers are synthetic and not secure. They do not replace measurements or a validated model.

What is the Engineering test data mode, and is it real measurement data?

It makes labelled synthetic datasets for checking calculations, software and spreadsheets: for example 50 observations of voltage 210 to 250 V, current 0 to 100 A, frequency 45 to 55 Hz and power factor 0.70 to 1.00, with a seed so the dataset can be rebuilt exactly. Each parameter has its own limits, distribution, decimal places and optional tolerance. Can I use the engineering data as real measurements? No. The values are simulated from simple random models. They are not field measurements, equipment test results or compliance evidence, and every exported row is labelled SYNTHETIC so the file cannot be mistaken for real data. How does the measurement tolerance work? Enter an amount in the unit (0.5) or a percentage of each value (1%). A second column is added where each reading is the simulated value plus an error spread evenly between minus and plus the tolerance, rounded to the same decimal places. It is a model of an instrument within its stated tolerance, not a calibration result.

Is anything sent to a server, and does the page remember what I generated?

No. Everything runs in your browser and nothing you enter or generate leaves your device. Does the page remember what I generated? Only inside the open tab. The Generation history panel keeps your last 20 results so you can show one again or run its settings again. It is never saved or sent anywhere, and reloading the page clears it. Use Clear results to empty the current result or Clear history to empty the list.
