About this calculator

This page calculates minimum cross-section, standard size, cable loss at that size and 1 more result from circuit current, series cable loop length, lamp load on the circuit, allowed cable loss and 2 more inputs. Change any value or its unit and the result updates. The steps below show the working for the default values, so you can check each line against your own method.

Limits of this calculator

Check the chosen size against the cable manufacturer data, the maximum voltage the CCR can supply and the insulation rating before ordering.

Formula

A ≥ ρ(T) × L × I² / (limit × Plamp) Ploss = I² × ρ(T) × L / A

Worked example

InputValue
Circuit current6.6 A
Series cable loop length4,000 m
Lamp load on the circuit3.176 kW
Allowed cable loss (% of lamp load)15
Conductor materialCopper
Conductor temperature (°C)20
  1. Allowed loss = 15% × 3.176 kW = 476.4 W
  2. A = ρ(T) × L × I² / allowed = 6.306 mm²
  3. Next standard size = 10 mm², loss 300.4 W

Assumptions

  • Standard sizes from the IEC 60228 preferred series, 1.5 to 630 mm²
  • The loss limit is a project choice, not a value from a standard

How it is calculated

Each input is converted to the base unit of its quantity, the formula above is applied in the order shown in the worked example, and each result is shown in the unit you choose. Results are held at full precision and rounded only for display, except where a step selects a standard size, as the worked example shows. A value outside its allowed range is refused with a message instead of giving a result.

Frequently asked questions

What do I need to enter?

Enter circuit current, series cable loop length, lamp load on the circuit, allowed cable loss (% of lamp load), conductor material and conductor temperature (°C). Change the unit of a value with its selector and the result stays the same.

What does this calculator assume?

Resistivity as in the loop resistance calculator. Standard sizes from the IEC 60228 preferred series, 1.5 to 630 mm². The loss limit is a project choice, not a value from a standard.

Which calculators should I use next?
