Limits of this calculator

Pick the mode, enter only the inputs for that mode, and read the results. For an inverter, check that the DC bus is high enough: the fundamental can never reach the DC bus voltage, and the three-phase PWM output is 0.612 × ma × Vd line-to-line. For a DC-DC converter, treat the inductance and capacitance as minimum values, round up to a standard part, then check the inductor saturation current against the peak current and the capacitor ripple current rating. Power Converter Formula

Rectifier, ideal diodes, resistive load, Vm = √2 Vs: half-wave Vdc = Vm / π, Vrms = Vm / 2; full-wave bridge Vdc = 2 Vm / π, Vrms = Vm / √2; 3-phase half-wave Vdc = 3√3 Vm / 2π, Vrms = Vm √(1/2 + 3√3 / 8π) (Vm per phase); 3-phase bridge Vdc = 3 Vm / π, Vrms = Vm √(1/2 + 3√3 / 4π) (Vm line-to-line); FF = Vrms / Vdc, RF = √(FF² − 1), fr = p f. With capacitor: Vfl = Vm / (1 + 1 / (2 fr C RL)), Vrpp = Vfl / (fr C RL). Inverter: 1-phase square V1 = 4 Vd / (π√2), Vo = Vd; 1-phase PWM V1 = ma Vd / √2; 3-phase six-step VLL1 = √6 Vd / π, Vo = √(2/3) Vd; 3-phase PWM VLL1 = √3 ma Vd / (2√2). DC-DC (CCM): buck D = Vo / Vin, L = Vo (1 − D) / (fsw ΔIL), C = ΔIL / (8 fsw ΔV); boost D = 1 − Vin / Vo, L = Vin D / (fsw ΔIL), C = Io D / (fsw ΔV); buck-boost D = Vo / (Vin + Vo), L = Vin D / (fsw ΔIL), C = Io D / (fsw ΔV).

Assumptions and Limitations

  • Rectifier: ideal diodes with no forward drop and no source impedance, a purely resistive load and a sinusoidal supply. The diode currents shown are for that load without the capacitor; with a capacitor the diodes carry short pulses whose peak is several times the average, so the diode ratings must be checked separately. The capacitor formula treats the output as a falling straight line between peaks and is accurate only for small ripple
  • Rectifier supply voltage is RMS: single-phase circuits use the voltage applied to the rectifier, the three-phase half-wave circuit uses the phase voltage and the three-phase bridge uses the line-to-line voltage. The peak inverse voltage is for the circuit named, not for a centre-tapped full-wave rectifier (which needs twice the peak)
  • Inverter: the DC bus is steady and the switches are ideal with no dead time. PWM figures are for the fundamental in the linear range only: overmodulation is not covered, and the carrier-frequency harmonics are not summed, so the total RMS and the distortion are shown only for the square-wave and six-step cases, where they are exact. Three-phase voltages are line-to-line unless marked as phase voltages
  • DC-DC converter: continuous conduction only, with ideal switch, diode, inductor and capacitor, so the duty cycle is the lossless value and the efficiency is used only for the input current and the loss. The inductor ripple is a percentage of the average inductor current (for a buck this is the load current, for a boost or buck-boost it is the load current ÷ (1 − D)). The output ripple is from the capacitance alone: the ESR of a real capacitor, which often dominates, is not included. The buck-boost output is of opposite polarity and its magnitude is entered

The diode currents shown are for that load without the capacitor; with a capacitor the diodes carry short pulses whose peak is several times the average, so the diode ratings must be checked separately. Rectifier supply voltage is RMS: single-phase circuits use the voltage applied to the rectifier, the three-phase half-wave circuit uses the phase voltage and the three-phase bridge uses the line-to-line voltage.
