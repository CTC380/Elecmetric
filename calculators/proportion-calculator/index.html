How to solve a proportion

A proportion says that two ratios are equal. For A : B = C : D the cross products are equal as well: A × D = B × C. Put in the three known terms, then divide both sides by the number that multiplies the missing term. For 3 : 4 = 9 : x the working is:

  1. Write the proportion with x for the missing term (term D): 3 : 4 = 9 : x.
  2. In a proportion the cross products are equal: A × D = B × C. Here that is 3 × x = 4 × 9.
  3. Put the known terms into the cross product. The side without x is B × C = 4 × 9 = 36.
  4. So 3 × x = 36. Divide both sides by 3: x = 36 ÷ 3 = 12.
  5. Check by putting 12 back in: 3 : 4 = 9 : 12. A × D = 36 and B × C = 36.
  6. Simplest forms: 3 : 4 simplifies to 3 : 4 and 9 : 12 simplifies to 3 : 4, the same ratio.

Rules this calculator follows

  • Cross multiplication. A : B = C : D means A × D = B × C. The missing term is found as (the two terms on the other side of the equation, multiplied) ÷ (the term opposite the missing one).
  • Order is kept. 2 : 3 = 4 : x is not the same as 3 : 2 = 4 : x. The terms are never sorted.
  • Terms are zero or positive. A ratio compares sizes of like quantities, so a negative term is refused with a message, as in the Ratio Simplifier.
  • 0 : 0 is not a ratio. A pair of zeros is refused. If the term opposite the missing one is 0, the page reports either no solution or that any non-zero value works; it never divides by zero.
  • Exact arithmetic. Terms are exact fractions held in whole-number (BigInt) arithmetic, with no floating-point rounding. The answer is given exactly, and as a decimal to the places you choose.
  • Checked every time. The page puts the answer back into the proportion, compares the cross products exactly and reduces both ratios to their simplest form before it says the result is verified.

3 : 4 = 0 : xNo solutionThe cross product forces x = 0, and 0 : 0 is not a ratio.
0 : 5 = 0 : xAny non-zero valueBoth ratios are 0 : something, so any non-zero x works and the answer is not fixed.
0 : 0 = 3 : xrefusedA ratio of 0 : 0 is not defined, so it cannot be one side of a proportion.

These are decided from the definition: the two ratios are equal when the cross products are equal and neither ratio is 0 : 0.

Direct and inverse proportion

This calculator solves a direct proportion A : B = C : D, where the two ratios are equal. An inverse proportion is a different relation, where one quantity falls as the other rises, so the products are equal instead: A × B = C × D. If 4 workers take 6 days, 3 workers take 24 ÷ 3 = 8 days. Do not enter an inverse problem as a direct proportion.

Questions

How do I solve a proportion?

Write the proportion as A : B = C : D, cross multiply to get A × D = B × C, put in the three known terms and divide by the number that multiplies the missing one. For 3 : 4 = 9 : x, 3x = 36, so x = 12.

How do I find the missing value in a ratio?

Leave the missing term blank, or type x, and enter the other three. The calculator works out the missing term in any of the four positions and shows the cross multiplication.

Can I use decimals and fractions?

Yes. Each term is read as an exact fraction, so 1.5 : 2.5 = 3 : x gives exactly 5 with no rounding. Mixed numbers such as 2 1/2 and fractions such as 3/4 also work.

What if the answer is not a whole number?

It is shown as an exact fraction and as a decimal. For 2 : 3 = 5 : x the answer is 15/2, or 7.5. A repeating decimal such as 14/3 is rounded to the places you choose and marked as approximate.

Why does the calculator say there is no solution?

A zero can make both sides of the cross product impossible to match. In 0 : 5 = 3 : x the left ratio has a first term of 0 and the right one does not, so no x works. In 3 : 4 = 0 : x the only candidate is x = 0, which would make 0 : 0.

How do I check whether four numbers form a proportion?

Enter all four terms. The calculator multiplies A × D and B × C exactly, compares them, shows the simplest form of each ratio, and says whether they are equal. For 3 : 4 = 9 : 13 they are not, and it suggests D = 12.

Is anything sent to a server?

No. The calculation runs in your browser. The history list is stored only in this browser and you can clear it.
