What the graph shows

The graph of y = ax² + bx + c is a parabola. It is symmetric about a vertical line through its vertex, which is its highest point if A is negative and its lowest point if A is positive. Every value in the table is worked out in exact fractions and radicals, and the picture is drawn from them. The x-intercepts are the roots of the equation, the same numbers that Mode 01 solves for.

Parabola Graph & Vertex Worked Example

For y = 2x² + 3x − 5 the vertex is at x = −B/(2A) = −3/4 = −0.75. Putting x = −3/4 back into the equation gives y = −49/8 = −6.125. Because A = 2 is positive, the curve opens upward and −49/8 is its minimum value. The curve crosses the y-axis at (0, −5) and the x-axis at (−5/2, 0) and (1, 0). Its mirror image of the y-intercept across the axis is (−3/2, −5). In vertex form the equation is y = 2(x + 3/4)² − 49/8.

Reading the roots from the graph

The discriminant decides how the curve meets the x-axis. When the vertex lies on the opposite side of the axis from the way the curve opens, the curve crosses the axis twice. When the vertex is on the axis it touches it once. When the vertex is on the same side as the opening direction, the curve never reaches the axis and the roots are complex.

A complex pair such as −1 ± 2i has a real part, −1, equal to the vertex x and an imaginary part that measures how far the vertex is from the axis. The roots are not points of the real graph, so the page lists them rather than plotting them.

Focus, directrix and width

Every parabola has a focus and a directrix: each point of the curve is exactly as far from the focus as from the directrix. For y = ax² + bx + c, with the vertex at (h, k), the focus is (h, k + 1/(4a)) and the directrix is the line y = k − 1/(4a). The width of the curve through the focus, the latus rectum, is 1/|a|. Tick the box above the graph to draw the focus and directrix. A larger |A| gives a narrower curve and a closer focus; these are the shapes used in reflectors and antennas.

Using the graph

Drag the graph to pan, turn the mouse wheel to zoom, or use the buttons. The sliders set A, B and C from −10 to 10 in steps of 0.5 and keep the window where it is, so you can watch the curve change. Typing a value or choosing an example refits the window. Click or tap the graph to read an approximate point; type an x in the Value at x box for an exact y. With the keyboard, focus the graph and use the arrow keys to pan, plus and minus to zoom and 0 to fit. Equal axes draws one unit the same length on both axes, so the true shape of the parabola shows.

Exact numbers, a drawn picture

Every printed value comes from exact arithmetic on fractions, so 0.1x² + 0.2x + 0.1 has its vertex at exactly (−1, 0) and touches the axis. Only the line itself is drawn in ordinary floating point, sampled at 480 points, so the picture can differ from the true curve by less than a pixel and never changes a printed number. Equations whose values are too large or too small to draw still get their exact results.

When A is zero

With A = 0 the equation is y = Bx + C, a straight line. There is no vertex and no axis of symmetry, so the page draws the line and gives its two intercepts. When A and B are both zero the graph is a horizontal line, y = C.

Questions

How do I find the vertex of a parabola?

Use h = −B/(2A) for the x-coordinate, then put h into the equation for the y-coordinate. For y = x² − 5x + 6 this gives h = 5/2 and k = −1/4.

Is the vertex the maximum or the minimum?

If A is positive the parabola opens upward and the vertex is the minimum. If A is negative it opens downward and the vertex is the maximum.

Why does the graph not cross the x-axis for some equations?

The discriminant is negative, so there are no real roots. The curve stays on one side of the axis. The complex roots are listed with the results.

What is the axis of symmetry?

It is the vertical line x = −B/(2A). Folding the graph along it places the left half exactly on the right half.

How do the sliders differ from typing a value?

Sliders keep the graph window fixed so you can see how the curve changes. Typing, or choosing an example, refits the window to the new curve. The sliders cover −10 to 10; type any other value in the box.

The calculation and the drawing run in your browser. This page also loads Google Tag Manager; data collected by tags depends on its configuration.
