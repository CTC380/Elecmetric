    How to use it

    Type an expression on the keyboard or use the keypad, and the result appears as you type. Press Enter or = to confirm a result and add it to the history. Escape or AC clears the expression.

    • Use * and / or the × and ÷ keys. Write a decimal point, not a comma.
    • Brackets can be nested, as in ((2+3)*4-5)/3.
    • After a confirmed result, typing + − × ÷ continues from the answer, and typing a digit starts a new calculation.

    Working with percent

    The % key divides by 100, so a percentage of a number is the number times the percentage: 15% of 200 is 200*15% = 30. To add a percentage, multiply by one plus the percentage: 200 plus 10 percent is 200*(1+10%) = 220, and 200 minus 10 percent is 200*(1-10%) = 180.

    Frequently asked questions

    How does this calculator read what I type?

    It uses its own expression parser, the same one as the Scientific Calculator. It does not use eval or run your text as code, and nothing you type leaves your browser. Multiplication and division are worked out before addition and subtraction, and brackets are worked out first.

    Does it work like a pocket calculator that does one operation at a time?

    No. You type the whole expression and see the result as you go, so 2+3*4 is 14, as in mathematics, and not 20. To work step by step, press = after each step and continue from the answer: typing an operator after = starts from the previous answer.

    What does the % key do?

    It divides the value before it by 100, so 200*15% is 30. It does not add a percentage to a total as some pocket calculators do: 200+10% is 200.1. For 200 plus 10 percent write 200*(1+10%), which is 220. The Percentage Calculator on this site handles increase, decrease and percentage change.

    Why does 0.1 + 0.2 show 0.3?

    Calculations use double-precision numbers, which hold about 15 to 17 significant digits. The display rounds to 10 significant digits, so the tiny binary rounding error in 0.1 + 0.2 does not show.

    What happens when I divide by zero?

    The calculator shows an error message and no result. A very large or very small result is shown in scientific form, such as 1.5×10¹⁵.

    How do I use memory?

    M+ adds the current result (or the expression you typed) to memory, M− subtracts it, MR puts the memory value into the expression and MC clears it. Memory is held in the page and disappears when you close it.

    Does it keep my calculations?

    No. The history and memory are held in the page and disappear when you close it. Nothing is stored or sent.

    When should I use the Scientific Calculator instead?

    Use it for trigonometry, logarithms, powers and roots of any order, factorials, complex numbers, polar form and SI prefixes for electrical work.
