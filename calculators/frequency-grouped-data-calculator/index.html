Entry formats
Raw observations 10, 10, 10, 12, 12, 15 (one list; tabulated for you) Value and frequency 10:3, 12:2, 15:1 (pairs with a colon) or two columns: 10 3 / 12 2 / 15 1 (space, comma or tab) Grouped classes 0-10 5 / 10-20 12 / 20-30 8 / 30-40 4 (lower-upper frequency, one class per line) also: 0 to 10 5 0–10, 5 0 10 5 and negative limits such as -10--5 3

Frequencies are whole-number counts of repeated observations. Classes must not overlap. Open-ended classes (such as "40 and over") cannot be used because they have no midpoint.

Frequencies and weights are different

A frequency says how many times an observation occurred, so it raises the sample size N and the sample divisor N − 1. A statistical weight says how much an observation should count, without changing N. They give different standard deviations, so they are not interchangeable. This calculator accepts frequency counts only; weighted statistics are not part of Mode 03.

Grouped-data estimates
Midpoint m = (lower + upper) / 2 Mean x̄ = Σ f m / N Variance Σ f (m − x̄)² / N (population) or / (N − 1) (sample) Median, Q1, Q3 L + ((p·N − CF) / f) × w p = ½, ¼, ¾ L lower limit of the class holding the p·N-th value, w its width, CF cumulative frequency before it, f its frequency Mode L + ((f₁ − f₀) / (2f₁ − f₀ − f₂)) × w one modal class, equal widths only

These are estimates. Once data are grouped, the original values are lost, and every observation is treated as if it sat at its class midpoint, so the true mean and standard deviation can differ. Sheppard's correction for grouping is not applied. Minimum and maximum are the outer class limits, not observed values.

Formulas (frequency tables)
N = Σ f x̄ = Σ f x / N SS = Σ f x² − (Σ f x)² / N σ² = SS / N s² = SS / (N − 1) MAD = Σ f |x − x̄| / N SE = s / √N CV = s / |x̄| × 100 % Median and quartiles are found by position in the cumulative frequencies, then interpolated (Inclusive, Exclusive or Tukey, as in Mode 02) — no list is expanded.
Verification

All values except the SD, SE and CV square roots are exact fractions. For small datasets the page also expands the table into a plain list and compares it with the Mode 02 engine (grouped data: the midpoints expanded by frequency).

Limits of this calculator

Statistics from a frequency table describe the table you enter; they do not check the data behind it. Grouped results are estimates and can differ from the statistics of the original observations. Standard deviation measures spread, not accuracy, and is not a substitute for calibration, measurement uncertainty evaluation or the acceptance criteria of the applicable standard. Treat as an estimate and have a competent engineer review it before it is relied on.
