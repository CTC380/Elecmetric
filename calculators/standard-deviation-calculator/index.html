Verification

Sums, mean, sum of squared deviations and both variances are computed with exact rational arithmetic, so there is no rounding error and no cancellation, however large the values or small the spread. Only the final square root is rounded, once, to the precision chosen. The check below runs an independent floating-point (Welford) calculation on your data and compares it.

Reference test vectors

Run in your browser against values from the product specification and from separately coded reference calculations.

Formulas
Population: σ² = Σ(xᵢ − μ)² / N σ = √σ² Sample: s² = Σ(xᵢ − x̄)² / (n − 1) s = √s² Mean: x̄ = Σxᵢ / n Shortcut used for exact sums: Σ(xᵢ − x̄)² = Σxᵢ² − (Σxᵢ)² / n

Use population when the list is the whole group you care about (every unit in a batch). Use sample when the list is a subset used to estimate a larger group (a few readings from a repeatable process). The n − 1 divisor makes the sample variance an unbiased estimator under the usual sampling assumptions; it does not make the sample standard deviation unbiased.

History

Limits of this calculator

Standard deviation measures spread (repeatability), not accuracy. A measuring system can give very consistent readings that are all wrong by the same offset, so this result is not a substitute for calibration, a measurement-uncertainty evaluation, or the acceptance criteria of the applicable standard. Treat as an estimate and have a competent engineer review it before it is relied on.
