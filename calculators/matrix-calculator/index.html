Questions

What operations does this matrix calculator do?

Addition, subtraction, multiplication, scalar multiplication, transpose and matrix power (including negative powers), plus determinant, inverse, rank, trace, minors, cofactors, adjugate and norms, for matrices up to 8 × 8. It also reduces matrices to REF and RREF and solves AX = B. It also computes LU, QR, Cholesky, SVD and Schur decompositions, eigenvalues and eigenvectors, least-squares solutions, the pseudo-inverse and the condition number. The electrical network group adds nodal and mesh analysis, Y-bus and Z-bus, incidence and loop matrices, state-space analysis, symmetrical components and DC power flow.

Are the results exact?

The basic operations, determinant, inverse, rank, RREF and equation solvers are exact: entries are stored as fractions, so 0.1 + 0.2 gives exactly 3/10. The decompositions (LU, QR, Cholesky, SVD, eigenvalues, Schur) are floating-point: they use double precision, about 16 significant digits, and show 7. Each one comes with checks that show how close the result is to the true answer. The network tools are floating-point too, and carry their own checks: KCL, KVL, power balance and round-trip tests.

How do you decide a matrix is singular, and what is the condition number?

The determinant is found with exact fractions, so it is exactly zero or it is not. A singular matrix has no inverse. A matrix that is only close to singular is not rejected. Instead the inverse step reports the condition number and warns when it is large. It measures how much small changes in a matrix change its inverse. This page shows the 1-norm condition number, the 1-norm of A times the 1-norm of its inverse. Values above about 10⁸ mean the matrix is ill-conditioned, so inverses of measured data should not be trusted.

How do I solve simultaneous equations, and how are the three cases told apart?

Put the coefficients in A and the right-hand sides in B, with one row per equation, then choose a solve method. For 2x + y = 5 and x + 3y = 7, A is [[2, 1], [1, 3]] and B is [[5], [7]], which gives x = 1.6 and y = 1.8. It compares rank(A) with rank([A | B]) and the number of unknowns. If rank([A | B]) is larger than rank(A), an equation reduces to 0 = c and there is no solution. If the ranks are equal and below the number of unknowns, there are free variables and the solutions are shown in terms of parameters t₁, t₂ and so on. If the ranks equal the number of unknowns, the solution is unique.

Which method should I use: Gauss-Jordan, Cramer, LU, QR or SVD?

Gauss-Jordan works for any system, including rectangular ones. Gaussian elimination shows the back-substitution. Cramer's rule and LU need a square A with a non-zero determinant. Cramer's rule is clear for small systems and slow for large ones, while LU is the usual choice for repeated solves. LU is the fast choice for solving square systems and finding determinants. QR is the stable choice for least squares. SVD is the most informative: it gives rank, condition number, the best low-rank approximations and the pseudo-inverse, and it is the safest way to decide whether a matrix is singular in the presence of rounding.

How do I know a decomposition is right?

Each result shows its own checks: for LU, QR, Cholesky, SVD and Schur the size of A minus the product of the factors; for QR, SVD and Schur how close the orthogonal or unitary factors are to orthogonal; for every eigenvalue and eigenvector the residual ‖Av − λv‖. Values near 1e-16 are rounding. If the input is ill-conditioned the status says reduced accuracy instead of presenting the numbers as certain.

Why are some eigenvalues complex, and what is a defective matrix?

A real matrix that is not symmetric can have complex eigenvalues. They come in conjugate pairs a + bi and a − bi. A rotation matrix such as [[0, −1], [1, 0]] has eigenvalues i and −i, because no real direction is left unchanged by a turn. Symmetric matrices always have real eigenvalues. Some matrices, such as [[2, 1], [0, 2]], have a repeated eigenvalue but only one independent eigenvector. They cannot be diagonalised as A = VΛV⁻¹. The calculator warns when it finds repeated eigenvalues with parallel eigenvectors.

What is the matrix exponential, and how is it computed?

e^A = I + A + A²/2! + A³/3! + … for a square matrix A. It solves the linear differential equation dx/dt = Ax, whose solution is x(t) = e^(At)·x(0), so it is used for state-space systems, transient analysis and Markov chains. It always exists and is always invertible, with inverse e^−A. To get e^(At), multiply A by t before entering it. It is not computed from the raw series, which loses accuracy for large matrices. The calculator scales A down, uses a degree-13 Padé approximant, and squares the result back up. The result is checked by e^A·e^−A = I and by comparing (e^(A/2))² with e^A.

How do I enter a circuit for nodal analysis?

Type one element per line: a name, two nodes and a value, for example R1 1 2 100. Names start with R, L, C, Z (a complex impedance such as 3+4j), Y (an admittance), V (a voltage source, positive terminal at the first node) or I (a current source flowing from the first node through the source to the second). Node 0 is ground. For AC, add a line such as freq 50 and give source values as phasors like 10<30. By modified nodal analysis. A voltage source fixes the difference between two node voltages instead of a current, so its current is added as an extra unknown and the matrix gets one more row and column for each source. The result shows the augmented matrix and the current in every source.
