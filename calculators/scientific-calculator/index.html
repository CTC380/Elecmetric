        How to use it

        Standard mode is a full scientific calculator: brackets and operator precedence, trigonometry, logarithms, powers and roots, factorials, constants, memory and the previous answer. Engineering mode adds complex numbers, rectangular and polar form, phasor arithmetic and SI prefixes for electrical work. Type on the keyboard or use the keypad. Press Enter or = to confirm a result and add it to the history, and use Add to worksheet to collect results with notes for printing or saving as a PDF.

        • Keyboard: type an expression, press Enter to confirm, Escape to clear. Use * and / or × and ÷. Powers are written with ^.
        • Functions take brackets, as in sin(30) or sqrt(16). Brackets are not needed for a single value: sin30 and √144 also work.
        • Variables: type a name, an equals sign and an expression, as in f=50, then press Enter. Use the name in later calculations, for example 1/(2*pi*f*100u). Names are letters only and are not case sensitive. The stored values appear under the result and are gone when you close the page.
        • Ans is the last confirmed result. MS, M+ and M− store, add to and subtract from memory, and MR enters it as mem.
        • An error is explained in words, for example division by zero, or a square root of a negative number outside Engineering mode.

        Angle modes

        The angle mode changes how trigonometric functions read their input. The same angle gives the same answer in each mode:

        Where a rule could be read two ways, the calculator follows the usual convention for scientific calculators: -2^2 is -4, and 2^3^2 is 2^9. Use brackets when in doubt. A product written without a sign, as in 3(4+5) or 2sin(30), is read as multiplication. The Implicit multiplication setting changes how a product with the sign left out ranks against division: by default 1/2π is (1/2)·π, and the other choice reads it as 1/(2π) so that 1/2πfC means 1/(2πfC). Explicit signs are never affected: 1/2*pi is always (1/2)·π. Two numbers side by side with a space, as in 1 000, are rejected rather than multiplied, so a thousands separator cannot silently change an answer.

        Limits and accuracy

        • Numbers are double precision (about 15 to 17 significant digits). Very large or very small results are shown in scientific form.
        • Factorials are limited to whole numbers up to 170. Larger values overflow.
        • An even root or a non-integer power of a negative number is an error in Standard mode, and a complex result in Engineering mode, using the principal value.
        • On a branch cut, such as asin(2), the sign of the imaginary part is a convention. Check it before using it in a design.
        • Phase angles are shown between -180° and 180°.
        • The calculator is a general mathematical tool. It does not know about units: the unit you choose in Engineering mode is a label on the result, and it is not checked.

        Frequently asked questions

        How does this calculator read what I type?

        It uses its own expression parser, written for this page. It does not use eval or run your text as code, and nothing you type leaves your browser. Brackets, operator order and functions follow the usual rules of mathematics.

        How do I switch between degrees, radians and gradians?

        Choose DEG, RAD or GRAD above the keypad. It sets how sin, cos and tan read their input and the unit of asin, acos and atan results. You can also write the degree sign after a value, as in sin(30°), and it is converted to the active unit.

        Why does sin(180) show 0 and not a tiny number?

        In degree and gradian mode the calculator uses exact values at multiples of 30 and 45 degrees, so sin(30) is exactly 0.5 and cos(90) is exactly 0. In radian mode a result that is only rounding noise, such as sin(π), is shown as 0.

        How do I enter complex numbers and polar values?

        Switch to Engineering mode. Write the imaginary unit as j, for example 10+j15. For polar input write the magnitude, the ∠ sign and the angle, for example 230∠30, or type 230<30. The angle follows the angle mode. Results show as rectangular and polar form, with a phasor diagram and the working.

        What do k, M, m, µ, n and p do in Engineering mode?

        Written directly after a number they are SI prefixes: 4.7k is 4,700, 100u is 100 microunits (0.0001) and 33n is 33 nano. They are not read as prefixes when a letter follows, so 3pi is 3 times pi.

        What does the % key do?

        It divides the value before it by 100, so 200*15% is 30. It does not add a percentage to a total: 50+10% is 50.1. For 50 plus 10 percent write 50*(1+10%).

        How many digits are right?

        Calculations use double-precision numbers, which hold about 15 to 17 significant digits. The display rounds to the number of significant digits you choose, 10 by default. Results can differ from exact mathematics in the last digits, for example 0.1+0.2 is shown as 0.3.

        How do I use a value again, such as a frequency?

        Type f=50 and press Enter. The name f then stands for 50 in every later calculation until you clear it or close the page. Names are letters only, up to 20 variables, and the names of functions and constants such as pi, e, i, j and ans are not allowed (i and j are both the imaginary unit, so i cannot stand for current; use a name such as ia). A name is read as one word, so write f c or f*c, not fc. A variable that holds a complex number needs Engineering mode.

        What does the Implicit multiplication setting do?

        It decides how 1/2π is read. With the default, a product with the sign left out ranks with multiply and divide, so 1/2π is (1/2)·π. With the other choice the product binds first, so 1/2π is 1/(2π), which is how the reactance formula 1/2πfC is usually meant. Use brackets to be sure.

        Does it keep my calculations?

        No. The history, the worksheet and any variables are held in the page and disappear when you close it. The Copy link button puts your expression in the link, so whoever opens the link sees the same calculation.

        Can I keep my results as a worksheet or a PDF?

        Yes. After a result appears, press Add to worksheet. Each entry keeps the expression, the result, the angle mode, the number of digits and any variable values it uses, and you can type a note beside it. Give the worksheet a title, then press Print or save as PDF and choose Save as PDF in the print window, or press Copy as text. The worksheet is built in your browser and is not stored or sent anywhere, so it is gone when you close the page.
